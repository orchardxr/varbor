## VarboR 0.1.4

- **Unsupported graphics engine warning for OpenVR games** (#6): when a game's D3D11 runs on an engine VarboR can't
  take frames from (e.g. Wine's wined3d), VarboR now says so on the first frame, with Quit Game / Run Anyway, instead
  of streaming a black screen.
- **DXMT is the default in the VarboR tools** (#5), as Proton defaults to DXVK: with no `CX_GRAPHICS_BACKEND` in the
  launch options, games under a VarboR tool use DXMT. Launch options and NotProton's Compatibility page still win.
- **OpenComposite registration the Linux way**: OpenComposite for macOS 0.1.1 no longer registers itself; WiVRn
  activates it while its server runs. Status now finds OpenComposite by its install and shows "WiVRn activates
  OpenComposite while it runs" instead of "not registered". OpenVR games find OpenComposite's install even when
  nothing is registered (e.g. WiVRn not started yet); a registered runtime still comes first.
