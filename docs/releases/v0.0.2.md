## What's new

- **No Homebrew needed.** The app now bundles the libraries the WiVRn server uses: glib, x264, librsvg, the Vulkan loader, MoltenVK and the rest. 0.0.1 failed to start on Macs without Homebrew (`Library not loaded: /opt/homebrew/...`).
- **Self-update.** MacVR checks GitHub for a new release at launch and every 6 hours. When there is one:
  - the menu shows **Install MacVR x.y.z**, and the Status page shows an Update section;
  - installing downloads the release, checks it, replaces the app and relaunches;
  - **Check for Updates…** is in the menu.

0.0.1 can't update itself, so install this version by hand once.

## Requirements

- An Apple Silicon Mac on macOS 14 or later.
- Steam with NotProton (CrossOver 27 Preview or 26.3 runners).
- A Quest with the stock WiVRn app (26.9) on the same network.

## Install

1. Unzip `MacVR-0.0.2.zip` and move `MacVR.app` to `/Applications`, replacing the old one.
2. The app is ad-hoc signed and not notarized. On first launch, right-click it and choose **Open**, or run `xattr -dr com.apple.quarantine /Applications/MacVR.app`.
