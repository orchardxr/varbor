## What's new

- **Check for Updates… always answers.** It shows an alert: install the new version now, read its release notes, or that you're already on the latest version. Before, a found update only added a menu item. Every check is now logged in `~/Library/Logs/MacVR/macvr.log`.
- **Pairing PIN** (from 0.0.3): while the server is waiting for a new headset, the PIN appears next to the MacVR icon in the menu bar, in the menu and on the Status page.
