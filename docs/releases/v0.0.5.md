## What's new

- **Unsupported graphics backend: a clear choice.** MacVR needs DXMT or DXVK. If a VR game starts with a different backend (WineD3D, or Automatic), you get an alert that explains how to fix it in Steam → Properties → Compatibility → Graphics. You can choose:
  - **Quit Game**;
  - **Run Anyway**: the game's VR start-up then fails as before.

  Before, you only got OpenComposite's `XR_ERROR_GRAPHICS_DEVICE_INVALID` error.
- **Exclude games from MacVR.** Games & Prefixes has a **Use MacVR** switch for each Steam game. Turning it off keeps MacVR's VR settings out of that game's prefix, and puts back whatever was there before. The CLI equivalent is `macvr exclude add|remove <appid> | list`.
- **Clearer updates.** When a new version is out:
  - MacVR asks once in an alert: install now, read the release notes, or later. It waits if a VR game is running.
  - Until you install it, the MacVR window shows an **Update to x.y.z** button in its toolbar and an update row at the top of every page.
  - **Check for Updates…** always answers with an alert, and every check is logged in `~/Library/Logs/MacVR/macvr.log`.
- **Pairing PIN** (from 0.0.3): while the server is waiting for a new headset, the PIN appears next to the MacVR icon in the menu bar, in the menu and on the Status page.
