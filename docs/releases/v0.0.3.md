## What's new

- **Pairing PIN shown in MacVR.** While the server is waiting for a new headset to pair, its PIN appears next to the MacVR icon in the menu bar, in the menu and on the Status page. Before, it was only in the server log.

Install it from the menu (**Install MacVR 0.0.3**) or from the Status page. 0.0.2 updates itself.
