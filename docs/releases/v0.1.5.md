## VarboR 0.1.5

- **VarboR is a Dock app**: the menu-bar icon is gone. Click VarboR in the Dock to show its window; closing the window
  keeps VarboR running in the Dock. The menu's commands moved:
  - the Dock icon's menu: Rescan Games, Open VarboR Log, Check for Updates (and Install when one is available);
  - the File menu: Rescan Games (⌘R) and Open VarboR Log; the VarboR menu: About, Check for Updates.
