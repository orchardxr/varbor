## MacVR is now VarboR

VarboR is the Wine side only: what Proton brings for VR games on Linux and CrossOver lacks. The WiVRn server and
OpenComposite are now separate apps, each updating itself:

- [WiVRn for macOS](https://github.com/orchardxr/wivrn-macos): server, dashboard (pairing PIN, headset) and the OpenXR runtime.
- [OpenComposite for macOS](https://github.com/orchardxr/opencomposite-macos): the OpenVR runtime, now native with Metal.

Install both before you update. VarboR's Status page shows whether they're there and new enough, with links.

## What's new

- **OpenVR games through Proton's vrclient**, built for CrossOver, into the native OpenComposite: no Windows
  OpenComposite DLL and no VR_OVERRIDE any more.
- **VarboR runner**: under Runners, Install Engines builds a copy of a NotProton runner with VarboR's DXMT (the game's
  own eye textures, no copy) and an ARM64EC DXVK for FEX, from [varbor-engines](https://github.com/orchardxr/varbor-engines).
- The status no longer shows the server, PIN, headset or game: the WiVRn dashboard does.

## Coming from MacVR

Quit MacVR and delete MacVR.app, then open VarboR: it takes over MacVR's settings
(`~/Library/Application Support/macvr` becomes `varbor`). While MacVR runs, VarboR changes nothing. MacVR 0.0.5 can't update itself to VarboR: download
`VarboR-0.1.0.zip` below and move VarboR.app to Applications.
