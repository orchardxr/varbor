## VarboR 0.1.0

The first VarboR release: what Proton brings for Windows VR games on Linux and CrossOver lacks, for Steam games under
NotProton on Apple Silicon.

- **OpenVR games** through Proton's vrclient, built for CrossOver, into [OpenComposite for macOS](https://github.com/orchardxr/opencomposite-macos) (Metal).
- **OpenXR games** through wineopenxr into the [WiVRn for macOS](https://github.com/orchardxr/wivrn-macos) runtime.
- **VarboR runner**: under Runners, Install Engines builds a copy of a NotProton runner with VarboR's DXMT (the game's
  own eye textures, no copy) and an ARM64EC DXVK for FEX, from [varbor-engines](https://github.com/orchardxr/varbor-engines).
- **Status** shows NotProton and its runners, WiVRn, OpenComposite (with links when missing or too old), the runners'
  bridge files and the prefixes. Every NotProton runner and prefix is set up at each launch; nothing to edit by hand.

WiVRn and OpenComposite are separate apps that install and update themselves; install them first. Streams to any
WiVRn-supported headset (tested on Quest 3S).
